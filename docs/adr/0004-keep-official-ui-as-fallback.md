# ADR-0004 — 保留官方 UI 插件作为回落

- 状态：**已采纳**
- 日期：2026-08-17
- 相关：[ARCHITECTURE.md §9](../../ARCHITECTURE.md)、[surface-manifest.md](../surface-manifest.md)

## 背景

`main` 分支的架构宣言写着「不叠 `dsh-web-app` 当产品 UI」，`codex/agent-sidebar` 分支把这句话执行成了「**自建 client roster，不把官方 UI 插件放进插件图**」（提交原话：*Compose our own client roster instead of stacking dsh-web-app*）。

思路是干净的：既然要做原生客户端，就别把官方 Web UI 装进来占内存、抢渲染、还得想办法藏起来。

## 问题

但在「**逐个**替换」的前提下，把官方 UI 插件移出插件图会同时拿掉四样东西：

1. **回落**。原生实现出问题时，没有东西可以接管 —— 用户看到的是空白，而不是退回到能用的 Web 版。
2. **崩溃自动接管**。官方 `ui-slots` 的 `abdicate` 机制（崩溃条目退位 → 下一 priority 接管）需要 cell 里**有下一个条目**。roster 里没有官方组件 = 退位后是空的，机制退化成白屏。
3. **对照基准**。`mirrored` 态要求原生与官方**同时**跑在同一份真实数据上做截图/交互 diff。官方不在图里，就没有基准可比，只能靠人肉记忆「原来长什么样」。
4. **用户主权**。用户没法把某块 UI 掰回 Web，只能接受我们的原生实现或者不用。

而收益只有一项：省掉官方 UI 插件的内存与初始化开销。

在**迁移期**（会持续到 W7），这个交换明显不划算：我们拿产品的安全网去换一点内存。

## 决定

**profile 里保留完整的官方 client `ui-*` 插件树。** 不移除、不 stub、不 no-op。

替换靠 [ADR-0001](./0001-slot-shadowing-over-css-hiding.md) 的 priority 遮蔽实现：官方注册在 priority 0，我们注册在 `-1`。**官方组件不渲染，但保持注册。**

`retired` 状态的语义因此要说清楚：它表示「官方实现对本产品不再有意义」，**不表示「把它从插件图里删掉」**。它仍然在 cell 里排队，等着接崩溃退位。

## 理由

- **迁移期最贵的东西是信心，不是内存。** 一个能随时退回官方 UI 的迁移，可以大胆推进；一个退不回去的迁移，每一步都要过度谨慎，反而更慢。
- **`abdicate` 是免费的产品级降级。** 官方把 `onEntryError` 注为 *"the supervision seam for hosts"* —— 上游明确预期宿主来监管条目崩溃。保留官方条目就等于白拿一层「原生崩了自动回落 Web」的容错，这是自己写多少代码都换不来的。
- **`mirrored` 依赖它。** 见 [surface-manifest.md §4](../surface-manifest.md)：`mirrored` 是把自己注册在**更高** priority 上「陪跑」，官方仍然渲染。没有官方条目，这一态不存在，验证手段就只剩「直接翻 native 看用户反应」。
- **生态不是黑洞。** 保留官方插件树也顺带保留了第三方 client 插件的显示能力（它们往 `list` / `keyed` 插槽注册）。Studio 的价值是把桌面做成一等公民，不是把别人的插件挤出去（见 [slot-map.md §9](../slot-map.md)）。

## 后果

**接受：**

- 迁移期内存与启动开销更高：官方 UI 插件全部加载、初始化、订阅数据，只是不渲染。
  - 量级判断：不渲染的 React 组件树成本主要在订阅与状态计算，可观测但不致命。若确实成为问题，正确解法是**逐插槽**评估卸载（W7 之后官方组件已无回落价值时），而不是一开始就全砍。
- 官方组件仍在跑，可能仍会拉数据、仍会产生副作用。需要在 soak 阶段确认没有重复请求/重复通知这类可观测的双份行为。

**换来：**

- 每个插槽都有一键回退（改配置，不发版）。
- 原生实现崩溃 → 官方自动接管，用户不见白屏。
- `mirrored` 对照验证成立。
- 用户能覆盖我们的任何选择。

**何时重新评估：**
W7 完成（`root` 已原生化、WebView 不再渲染 UI）之后。那时候「保留官方 UI 作回落」的价值随 WebView 一起归零，可以在 W8 连同 client 半一起拆除。**在此之前，任何「把官方 UI 插件从图里去掉」的提议都应被拒绝，并指向本 ADR。**
